# 写真・ロゴの元データ置き場

オーナーがGitHubから直接アップロードする場所です。ここのファイルは**加工前の元データ**として残し、サイトで使う画像は別のフォルダに書き出します。

- `logo/`：ロゴ（SVG・AI・PDF・EPSがあれば最優先。なければ大きいPNG）
- `photos/`：写真（スマホで撮ったままのJPEG・HEICで可）

## アップロード前に確認すること
- お客様の車のナンバープレート、お客様の顔、書類などの個人情報が写っていないか
- スタッフの顔写真は本人の了承があるか
- 1ファイル25MBまで（GitHubの画面からのアップロード上限）

ファイル名は何でも大丈夫です。どこで使ってほしいかの希望があれば、ファイル名やコミットメッセージに書いてください（例：`店舗外観_看板.jpg`）。
