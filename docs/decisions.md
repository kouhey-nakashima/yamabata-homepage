# 設計上の決定事項

> 2026-11-13作成。**「確定」「未決定」**を区別する。変更した場合は理由・日付を追記する。

## D-001 HPとCRMは別リポジトリ・別アプリ（確定、2026-11-13）
- HPのリニューアルはこのリポジトリで行う。CRM・お客様向け見積フォーム・予約フォームは `car-auto-crm` が担当する（car-auto-crm の D-002・D-029）。
- HPは顧客の個人情報を扱わない。CRMとはリンクのみでつなぐ。
- 理由：公開サイトと個人情報を扱うシステムを分け、設定ミスによる漏えいを防ぐ。デプロイや依存関係が互いに影響しないようにする。

- CRM：本番 `crm.yamabata-motors.com`（予定）、開発 `crm-dev.yamabata-motors.com`（稼働中）
- ドメインのDNSはCloudflareで管理（2026-10-31にエックスサーバーのDNSから移管。既存のレコードはエックスサーバーと同じ内容で、メールのためA 3件は「DNSのみ」）。

## D-003 基盤（確定、2026-11-13）
- Cloudflare（EmDash）で運用する。CRMと同じCloudflareアカウント・請求にまとめる（car-auto-crm の D-012）。

- Cloudflareアカウント：`yamabata-motors.com`のゾーンがあるアカウント（CRMの`car-auto-crm-dev`と同じ）を使う（2026-11-13 オーナー確認）。確認用URL（Cloudflare Pages）もこのアカウントに作る。

- 専用の下層ページは作らない。トップページと修理事例ページ（2026-11-13追加指示）の1セクションとして掲載する。似顔絵アイコン（写真は使わない）＋年代・性別・ご利用内容＋感想。

## D-008 EmDash で作り、ブログを付ける（確定、2026-11-13）
- オーナー指示：今後は EmDash（Cloudflare の CMS、Astro ベース）で作り、ブログで発信する。
- 構成：`site/` に EmDash 1.5（Cloudflare 用ブログテンプレートを元に作成）。Worker＋D1＋R2。デザインは試作（`prototype/`）をそのまま移植。
- 固定ページ（車検・修理・整備・修理事例・中古車販売・保険代理・会社概要・トップ）はコード管理。**ブログ記事だけ**を管理画面で書く（店舗の手間を減らし、デザイン崩れを防ぐ）。
- ブログ：`/blog`（一覧）、`/blog/記事`、`/blog/category/カテゴリー`、`/rss.xml`。カテゴリーは「お知らせ／車検・整備／修理のこと／車選び／スタッフ日記」。トップに新着3件。
- コメント機能・タグ・サイト内検索は使わない（管理の手間と迷惑投稿を避ける）。必要になったら追加。
- `prototype/` は確認用（Cloudflare Pages）として当面残し、EmDash 版の公開後に役目を終える。

## D-009 リニューアルの目的（確定、2026-11-13 オーナー）
- ①サイトをしっかり運用する ②SEO対策 ③公式LINEと連携し「LINEで30秒、車検の概算見積り」というキャッチコピーでLINE登録者を増やす。
- LINE誘導は全ページの主な行動（電話より優先して目立たせる）。文言は `site/src/data/site.ts` の `LINE_CTA` で一元管理。
- 「30秒見積り」はCRM側のLINE内見積フォーム（LIFF、CRMのD-029）が前提。動く前に公開する場合は `ESTIMATE_LIVE=false` で「LINEで相談」の文言にする（できないことをうたわない）。
- 計画と実装状況は [operations.md](operations.md)。
