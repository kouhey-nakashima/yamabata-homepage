# 運用・SEO・LINE誘導の計画

> 2026-11-13作成。リニューアルの目的（[D-009](decisions.md)）を達成するための運用計画。「実装済み」と「これからやること」を分けて書く。

## 目的（オーナー）
1. サイトをしっかり運用する（更新が止まらない）
2. SEO対策（「奄美市 車検」などで見つけてもらう）
3. 公式LINEと連携し、「LINEで30秒、車検の概算見積り」でLINE登録者を増やす

## 実装済み（`site/`、2026-11-13、ローカル確認済み・未公開）
### LINE誘導
- 「LINEで30秒、車検の概算見積り」の誘導枠（`src/components/LineCta.astro`。2026-11-13にデザイン刷新：紺の背景に大きな「30秒」、LINE画面のイメージ、立体の緑ボタン）：トップ（ヒーロー直下）、車検（料金の直後）、修理・整備、修理事例、中古車販売。PCではQRコード（`public/img/line-qr.png`、`https://lin.ee/91lyUYb`）も表示
- トップのヒーローに緑の「LINEで30秒見積り」ボタン、スマホ下部の固定ボタン、お問い合わせ欄のボタンも同じ文言
- 文言は `src/data/site.ts` の `LINE_CTA` にまとめている。**30秒見積り（CRM側のLINE内見積フォーム、LIFF）が動く前に本番公開する場合は `ESTIMATE_LIVE = false`** にすると「LINEで相談」に切り替わる（できないことをうたわない）
- 概算である旨の注記（「正式な金額は点検後」）を必ず表示（CRMのD-029と同じ）

### SEO
- 各ページのタイトルに地域名（例：「奄美市の車検｜株式会社山畑自動車」）と説明文
- 正規URL（canonical）、OGP（SNSでシェアした時の画像 `img/og.jpg`・タイトル・説明）
- 店舗の構造化データ（JSON-LD、`AutoRepair`：住所・電話・営業時間 火〜土 9:00〜17:00・対応地域・Instagram／LINE）
- サイトマップ：ブログ記事は EmDash の `/sitemap.xml`、固定ページは `/sitemap-pages.xml`。`robots.txt` は EmDash が出力（管理画面は除外）
- ブログ（カテゴリー別一覧・RSS）で地域の車の情報を発信できる

### 計測
- Google アナリティクス 4 の測定IDを `src/data/site.ts` の `GA4_ID` に入れると有効になる。LINEボタンのクリックを `line_click`（押された場所：hero／top／shaken／repair／cases／sales／contact／sp-bar）として記録する
